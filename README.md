# Gerenciador de Simulados

Plataforma web para treino pré-prova com questões de múltipla escolha, correção automática e histórico de desempenho.

## Funcionalidades

- Cadastro e login de usuários (com senha criptografada)
- CRUD completo de provas e questões
- Treino com alternativas e correção automática
- Nota colorida por desempenho (verde/amarelo/vermelho)
- Histórico de treinos por usuário
- Permissões: só o autor ou admin edita a prova
- Interface responsiva (desktop e mobile)

## Tecnologias

- Python 3.14
- Flask (Blueprints + Application Factory)
- SQLite (banco de dados relacional)
- Jinja2 (templates)
- HTML semântico + CSS Grid responsivo
- JavaScript vanilla
- Pytest (testes)
- Git/GitHub (colaboração)
