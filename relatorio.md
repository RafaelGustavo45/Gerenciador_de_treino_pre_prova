Dificuldades encontradas e como foram superadas.

A maior dificuldade encontrada foi o preenchimento de alternativas, houve uma confusão na qual o colega pensou que era alternativas de escrever a resposta, porem era de alternativas, e assim ele fez fora do planejado
Nessa mesma dificuldade no sistema houve dificuldade para o usuario definir questões e alternativas, já que era separado e em cada iteração o usuario criavava uma questão e só depois cada alternativa
Para superar isso foi usado javascript para a geração de relatórios dinamicos e alteração da API interna para suportar entrada conjunta de dados para criar questões e suas alternativas
